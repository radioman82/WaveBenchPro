# Security

This is experimental desktop audio software, with no security support SLA or designated long-term supported release.

Native VST3 plugins execute with the user's permissions in the app process; isolation is not implemented. Use trusted plugins and keep backups.

Ordinary defects: [Issues](https://github.com/radioman82/WaveBenchPro/issues). For vulnerabilities, first check whether GitHub offers [private vulnerability reporting](https://github.com/radioman82/WaveBenchPro/security/advisories/new) for this repository. This document does not assume/enable that feature. If unavailable, open a minimal issue requesting a private contact route, without exploit details or private data.

No mailbox, response deadline, signing identity or handling service is promised. Review screenshots/logs before sharing.
